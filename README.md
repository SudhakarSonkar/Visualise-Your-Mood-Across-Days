# 📔 Diary Tone Analyzer

An interactive **Streamlit web app** that analyzes the **positivity** and **negativity** of your diary entries using **NLTK Sentiment Analysis**.  
It visualizes your emotional trends over time with beautiful **Plotly line charts**.  

---

## 🚀 Features  
- Automatically scans all `.txt` files in the `diary/` folder.  
- Uses **NLTK’s SentimentIntensityAnalyzer** to calculate:  
  - 😀 **Positivity** score  
  - 😞 **Negativity** score  
- Displays **interactive line charts** of emotional trends across dates.  

---

## 🛠 Tech Stack  
- [Streamlit](https://streamlit.io/) – for building the web app  
- [Plotly Express](https://plotly.com/python/plotly-express/) – for visualization  
- [NLTK (VADER Sentiment Analysis)](https://www.nltk.org/) – for sentiment scoring  
- Python Standard Libraries: `glob`
